How to play!

Try to name as many pokemon in a row as possible

simply type in a pokemon and hit enter

No repeating pokemon!! If you do, the game ends!

You have to spell the pokemon correctly and don't capitalize, please use the autocomplete.

Try to get as many as you can!

Megas and Formes do NOT count as their own pokemon, and this game is current only up to gen 9
